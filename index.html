01 · about

From AKS to a Raspberry Pi rack.

I'm an AI Engineer who came up through backend systems first — which means I think about an LLM the way I think about any other dependency: what's the latency budget, what happens when it's slow, and how do I know if it's wrong before a customer does.

At Altolabs, that means working on AI products, retrieval pipelines, LLM integrations, and the Java and Python services behind them. Before that, at Mondee, I worked on AI-driven personalization and automation. Each role has sharpened the same instinct: a model is only as good as the system feeding it and the one reading its output.

Off the clock, I run a MicroK8s homelab across Raspberry Pi 5 and Proxmox, with TrueNAS storage and self-hosted Immich, Pydio, and n8n. Keeping it running has brought its share of 2 a.m. debugging — the same instincts apply at work — happy to talk through it.
